# Black-Box Optimisation Capstone

Capstone project for the Imperial College Professional Certificate in Machine
Learning and Artificial Intelligence.

## In plain terms (non-technical summary)

Think of eight locked dials. Each turns a handful of numbers between 0 and 1 into
a single score, and there is no manual saying what any of them do. The job is to
find the settings that give the highest score, with only one attempt per dial
each round, so every attempt has to be chosen with care. The code learns from
what each attempt returns, builds a rough picture of how each dial behaves, and
uses that to decide where to try next, weighing safe tweaks against bolder moves.
The outcomes were mixed: one dial improved severalfold, a few climbed steadily,
and one never really responded.

## What the task is

For each of eight unknown functions, find the input that produces the highest
output. There is no formula and no gradient, only a scalar returned after each
query, with one query per function per round. Inputs are vectors in `[0, 1]`
ranging from 2 to 8 dimensions by function, and output scales differ widely
between functions.

## How it works

The approach is Bayesian optimisation with a Gaussian Process surrogate. For each
function the code fits a GP with per-dimension length scales (ARD), chooses the
kernel between RBF and Matérn by leave-one-out error, and uses a UCB or EI
acquisition function to propose the next query. Leave-one-out diagnostics (RMSE
and a calibration score) are reported alongside the best value found so far. The
method is documented in full in the model card.

## Running it

```bash
pip install -r requirements.txt

# command line: prints the per-function table and writes results/best_so_far.png
python src/run_all.py

# or step through the notebook
jupyter notebook notebooks/bbo_optimisation.ipynb
```

Random seeds are fixed in `src/bbo.py`, so re-running reproduces the same
numbers. The data under `data/history/` is the record of queries submitted over
the rounds (input vectors and returned outputs, one row per round per function).
