# Initial datasets

The starting observations provided for each function, as paired NumPy arrays.

Expected files (replace these placeholders with the real arrays):

- `initial_inputs.npy` — input coordinates, shape `(n_points, dims)`
- `initial_outputs.npy` — scalar outputs, shape `(n_points,)`

Each input dimension is bounded to `[0, 1]`. Dimensionality per function is
listed in the top-level README.
